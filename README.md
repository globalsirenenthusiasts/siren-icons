# SirenSpotter sirenicons

This repository contains a collection of icons used on the SirenSpotter map, among other places. All icons are free to use in other projects and applications as well.

Contributions of new icons to this repository are always welcome!

## Icon Guidelines

- Icons must be created as **SVG files** with dimensions of **128 × 128 px**.
- The icon itself must be **white on a transparent background**.
- To use an icon in **SirenSpotter**, it must be exported as a **PNG or WebP file**.
